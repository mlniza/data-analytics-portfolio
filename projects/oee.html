Background

From blind spots to real-time visibility

In a manufacturing environment, machine downtime and performance drops often go unnoticed until they've already impacted production output. Without a centralized monitoring system, operators and supervisors had to rely on manual checks and periodic reports — reactive rather than proactive.

This project was developed during my internship to solve that problem: building a live data pipeline and monitoring dashboard for 4 production machines — PU Cabinet N5, PU Door N5, Thermodoor N5, and N5 Final — giving the production team full visibility into machine health at any moment.

Data is inputted by IoT tools at regular intervals, covering running time, breakdown duration, good output, reject count, and takt time. This feeds directly into the MySQL database, which Metabase queries to render the live dashboard.

Metric Definition

How OEE is calculated

OEE (Overall Equipment Effectiveness) is the gold standard for measuring manufacturing productivity. It is the product of three factors:

Metric Formula PU Cabinet N5
Availability Run Time / Planned Production Time 90,90%
Performance Actual Output / Ideal Output (Takt Time) 76,10%
Quality Good Units / Total Units Produced 100,00%
OEE Availability × Performance × Quality 69,20%
Low
< 65%
Medium
65% – 85%
Good
≥ 85%
Dashboard

Interactive monitoring view

The dashboard displays real-time status for each machine including machine running state, KPI metrics, hourly plan vs actual output, breakdown composition, and downtime distribution. An automated alert log captures anomaly events with timestamps.

Insight & Analysis

Key findings from PU Cabinet N5

69.2%
OEE Level: Medium
Below world-class standard of 85%, primarily driven by Performance at 76.10% despite perfect Quality score.
76.1%
Performance is the bottleneck
Speed loss is the main OEE depressor — machine runs below ideal throughput, not due to breakdowns.
82.6%
Downtime is Operational
82.56% of downtime is production-related (material change, setup, waiting), not machine failure (17.44%).
100%
Quality is Perfect
Zero Defects Quality holds at 100%. Every unit meets standard, eliminating quality loss as a concern entirely.

Recommendation: Since 82.56% of downtime is production-related rather than mechanical, improvement should focus on operational efficiency. Key areas include streamlining material supply and reducing non-value-added waiting time, rather than machine maintenance.
